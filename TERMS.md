# Terms of service

These terms cover the Meshtastic Discord bot, the application that provides the
`/bug`, `/feature`, `/faq`, `/changelog`, `/repo`, and `/tapsign` commands.
Using the bot means you accept them.

The bot is a volunteer-run part of the Meshtastic project. It exists to turn
reports from Discord into issues on GitHub.

## Your submissions are public

`/bug` and `/feature` create an issue in a public GitHub repository. The issue
records what you typed and your Discord username and user ID, and anyone can
read it. Do not submit anything you are unwilling to publish, including
passwords, keys, precise locations, or another person's information.

See the [privacy policy](PRIVACY.md) for what is recorded and how to ask for it
to be removed.

## Acceptable use

When using the bot, you must not:

- submit unlawful, abusive, harassing, or deliberately misleading content
- submit another person's information without their permission
- file issues in bulk, automate submissions, or otherwise use the bot to spam
  the repositories it writes to
- attempt to use the bot to gain access to systems or accounts

Maintainers may edit or delete issues created through the bot, and may block
anyone from using it. The rules of the Meshtastic Discord server and
[Discord's Terms of Service](https://discord.com/terms) also apply.

Only submit material you have the right to share.
